

# Customer Segmentation Using Machine Learning

## Project Overview
This project groups customers according to their annual income
and spending scores using K-Means clustering.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Workflow
1. Data loading and exploration
2. Exploratory data analysis
3. Feature scaling with StandardScaler
4. Elbow Method for cluster selection
5. K-Means clustering
6. Silhouette score evaluation
7. Customer segment analysis

## Dataset
Mall Customer Segmentation Dataset from Kaggle.

## Files
- Customer_Segmentation.ipynb: analysis and ML implementation
- README.md: project documentation

## Disclaimer
Clusters describe patterns in this dataset and should not be
treated as definitive labels for individual customers.
